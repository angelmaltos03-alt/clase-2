NIVEL 1 · CONCEPTOS
EDI

📨 Comunicación automática

Electronic Data Interchange permite que los sistemas de empresas distintas intercambien documentos comerciales en formatos estandarizados.

Tienda→EDI→Proveedor

Ejemplos: órdenes de compra, confirmaciones y avisos de embarque.

DATA WAREHOUSE

🧠 Memoria para decidir

Un almacén de datos integra información histórica de distintas fuentes para analizar tendencias, comparar periodos y apoyar decisiones.

VentasInventarioFinanzas↓Data Warehouse

Ejemplos: comparar sucursales, descubrir productos más vendidos y planificar inventarios.

🧩 Microlección: ¿cuál resuelve qué?

1. Un proveedor necesita recibir automáticamente una orden de compra. ¿Qué tecnología se utiliza directamente para intercambiar ese documento?
2. La gerencia quiere comparar las ventas de las últimas 12 temporadas. ¿Qué herramienta ayuda directamente?
Idea clave: EDI mueve documentos entre organizaciones; el Data Warehouse organiza datos para analizarlos. Se complementan, pero no son lo mismo.

NIVEL 3 · EDI

📨 Ordena el proceso de compra

Selecciona el paso que corresponde en cada posición. Recuerda: una confirmación no significa que la mercancía ya llegó.

Primero se decide qué comprar; después se envía la orden. El proveedor confirma, prepara el envío y transmite el ASN. Finalmente, el almacén verifica lo recibido y actualiza los sistemas.
