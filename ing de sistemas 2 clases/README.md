# Ingeniería de Sistemas II — Clases
## NovaTech Lab: misión interactiva sobre EDI y Data Warehousing

Aplicación educativa en HTML, CSS y JavaScript sin dependencias externas.

### Cómo usar
1. Abre `index.html` en un navegador moderno.
2. Avanza por los módulos de forma secuencial.
3. Resuelve preguntas, cálculos y retos; la plataforma da retroalimentación inmediata.
4. El progreso se guarda en el almacenamiento local del navegador.
5. Al final puedes descargar un informe de la misión o imprimirlo como PDF.

### Incluye
- Diseño adaptable con colores vibrantes y accesibilidad para movimiento reducido.
- Ruta de aprendizaje por niveles y barra de progreso.
- XP, rachas y mensajes de felicitación.
- Retroalimentación explicativa y pistas para corregir errores.
- Auditoría de inventarios, flujo EDI, ETL, modelo de Data Warehouse, ventas y evaluación financiera.
- Reto final y autoevaluación con informe descargable.

### Nota docente
Los datos empresariales son ficticios. La puntuación es formativa. Las respuestas abiertas reciben una revisión orientativa basada en longitud y términos clave; no es evaluación semántica ni sustituye la revisión del docente. El progreso se guarda solo en el navegador actual, no se sincroniza ni se envía al docente.

### Publicación
En GitHub, entra a **Settings → Pages**, selecciona **Deploy from a branch**, elige `main` y la carpeta raíz `/(root)`. La app estará en la ruta de esta carpeta. Si Pages no está habilitado, hay que activarlo manualmente.
